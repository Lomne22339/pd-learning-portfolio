# UNIX TCL & Bash Scripting

This project contains solutions for an assignment focused on basic UNIX/Linux, TCL, and Bash scripting.

## Objective

The objective of this assignment was to gain hands-on experience with:

UNIX/Linux command-line environments
TCL scripting
Bash shell scripting
Text file processing

## TCL Script

The code.tcl script analyzes a text file provided as a command-line argument.

### Usage

bashtclsh code.tcl sample.txt
