# Bash & TCL Text File Analysis

A basic scripting project completed as part of a **VLSI Design Flow (VDF) coursework assignment**.

The project implements the same text-file analysis task using two different scripting languages:

- **TCL**
- **Bash**

The purpose is to build hands-on familiarity with UNIX/Linux command-line environments, scripting fundamentals, command-line arguments, file handling, and text processing.

---

## Objective

The objective of this assignment is to gain practical experience with **UNIX/Linux and TCL scripting**.

The task is to create scripts that accept a text file as a command-line argument, analyze its contents, and display basic information about the file.
